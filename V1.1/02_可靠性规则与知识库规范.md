版本 V1.1 · Engineering Implementation Ready｜2026-11-22

> 修订性质：实施就绪版。DSL 执行规范、冲突裁决矩阵、评分模板与规模目标均为定案；配套机读附件：`rule.schema.json`、`unit_dictionary.yaml`、`dfmea_scoring_template.md`。变更对应《CHANGELOG.md》。

## 1. 知识分类
- 元器件：电阻、电容、电感、二极管、MOSFET/IGBT、IC、连接器、电池、晶振。
- PCB/PCBA：基材、叠层、铜箔、过孔、焊盘、焊料、涂覆、清洗、组装。
- 模块/传感器：摄像头、麦克风、扬声器、IMU、环境传感器、无线通信。
- 电源：AC/DC、DC/DC、LDO、充电、电池保护和功率路径。
- 失效机理：热疲劳、电迁移、介质击穿、ESD损伤、腐蚀、CAF、焊点疲劳、振动断裂、材料老化和参数漂移。
- 方法：降额、热设计、DFMEA、故障树、可靠性预计、DVP&R、HALT/HASS适用性。

## 2. 规则Schema
每条规则至少包含：
rule_id、domain、title、intent、applicability、inputs（名称/类型/单位/必填/来源）、preconditions、expression、thresholds、severity、rationale、recommendation、evidence、evidence_level、owner、reviewer、version、status、effective_date、expiry_date、tests。
**机读定义以 `rule.schema.json` 为准**（V1.1 新增）；本节为人读规范，两者不一致时以 JSON Schema 为准并修订本文。
阈值必须来自具体料号数据手册、适用标准、实测数据或批准企业规范；不得把示例值当通用行业限值。

示例（仅示意）：
```yaml
rule_id: ELEC-CAP-DCBIAS-001
title: MLCC直流偏压容量衰减审查
applicability: {component_category: MLCC}
inputs:
  - {name: operating_voltage, unit: V, required: true}
  - {name: capacitance_at_bias, unit: uF, required: true}
  - {name: required_min_capacitance, unit: uF, required: true}
expression: capacitance_at_bias >= required_min_capacitance
rationale: 有效电容量受直流偏压、温度及老化影响
recommendation: 核对制造商偏压曲线并验证最差工作点
evidence_level: A_or_B
status: draft
```

### 2.1 表达式与单位执行规范（V1.1 定案）
**处理流水线**（与 01 §3.1 一致）：
```
Rule Definition → Parser/AST（白名单+类型检查） → Unit Normalization（别名识别/SI归一/维度检查）
→ Deterministic Evaluator（确定性求值+边界校验） → Finding+Evidence
```
- 禁止 `eval()`、禁止 LLM 执行规则表达式、禁止动态导入与文件访问。
- 首版 DSL 能力边界：比较 `> >= < <= == !=`、逻辑 `AND OR NOT`、算术 `+ - * /`、受限 `IF`；**禁止任意函数调用**。需要函数/模型计算（如电解电容寿命公式）的规则走确定性计算服务，expression 只承载其结果与阈值的比较。
- **单位归一先于求值**：所有 inputs 先经单位库（附件 `unit_dictionary.yaml`）做别名识别、归一与维度检查；expression 内只做无量纲标量比较。不同物理维度直接比较直接报错。
- **温度双轨（r3 定案，复审 P0-2）**：温度类 input 必须声明 `quantity_kind: absolute | delta`。absolute 归一到 **K**（带 273.15 偏移）；delta（温差）归一到 **K 差值**（无偏移，°C 差值与 K 差值数值等价）。表达式只读取已归一值；未声明 quantity_kind 的温度报 TEMPERATURE_SCALE_AMBIGUOUS。复核例：SOA 折减因子按 delta 计算（25→1.00、85→0.52、150→0.00），若误用 absolute 归一（25→298.15）因子为 -1.185，即复审指出的算错场景。
- **单位别名表**：完整见 unit_dictionary.yaml（r3 含 ratio/table/degC_per_W/dimensionless/lifetime_hours/cycles 独立维度）。
- **错误语义**：缺失值、除零、单位不兼容、未知单位、温度歧义均返回明确错误码（MISSING_INPUT / DIV_BY_ZERO / DIMENSION_MISMATCH / UNKNOWN_UNIT / TEMPERATURE_SCALE_AMBIGUOUS），不自动猜测。
- 每条规则**发布（published）前**至少含正常、边界（阈值相等）、异常输入三类单测用例（`tests` 字段）；draft 期 ≥1 条即可通过 schema 校验（复审 P0-1③）。

### 2.2 分层规则类型与标准模板（V1.1 新增）
按复杂度将 rule_type 分为三类，每类有专属执行器（见 01 §3.1）与标准模板（机读文件：附件 `rule_templates.yaml`）：

| rule_type | 适用场景 | 执行器 | 模板示例 |
|---|---|---|---|
| **declarative_expr** | 静态布尔/四则规则（电阻功率降额、电压应力比） | 受限 DSL 求值器（asteval/simpleeval 类安全沙箱） | ELEC-RES-PWR-001 电阻稳态功耗降额 |
| **lookup_curve** | 二维曲线插值/包络（高温功率折减、MLCC 直流偏压、MOSFET SOA） | 曲线插值引擎（插值方法/温度折减/安全裕度可配置，边界越界显式报错） | ELEC-MOS-SOA-002 脉冲启动 SOA 包络 |
| **script_plugin** | 多步物理计算（Arrhenius 寿命、多热阻链结温、IPC-2152 载流） | 受控白名单计算插件（module 版本化 + 代码审计 + 只读输入） | ELEC-ECAP-LIFE-003 电解电容寿命评估 |

类型约束：
- declarative_expr 的 expression 受 §2.1 DSL 白名单约束；lookup_curve 的 curve_eval 块声明插值方法、温度折减因子与安全裕度系数；script_plugin 的 plugin_ref 块声明受控模块（module/entry_func/params + digest）与 outputs_exposed（逐项带 unit/quantity_kind）。
- script_plugin 数值精度受 03 §5.1 浮点容差约束（相对误差 ≤0.1% 或绝对误差小于工程最小有效位）；插件测试用例须含 expected_outputs 与 tolerance_rel。
- **preconditions 为机器可判定 DSL 数组**（r3 定案，复审 P0-3）：每项 `{expr, on_fail}`，expr 只读 inputs 变量（白名单同 §2.1），on_fail ∈ {SKIPPED_PRECONDITION, NOT_APPLICABLE, DATA_GAP}。人读说明放 notes 字段。
- **状态机四态**：缺输入→DATA_GAP；适用性不符→NOT_APPLICABLE；前置不满足→SKIPPED_PRECONDITION；来源冲突→CONFLICT_UNRESOLVED。优先级与负例要求见 01 §7.1。

## 3. 证据等级
| 等级 | 定义 | 使用限制 |
|---|---|---|
| A | 适用法规/标准原文、制造商受控数据手册、批准企业规范 | 可支持正式判定，须核对版本和适用性 |
| B | 受控实验室报告、审核过的仿真/实测数据、供应商受控资料 | 可支持工程判断，需说明边界 |
| C | 可复现内部案例、可靠性数据库、同行评审论文 | 风险提示及机理解释 |
| D | 专家经验、未充分验证记录、AI归纳 | 仅假设/建议，不可单独放行 |

证据记录发布者、文件名、版本日期、页码/章节、料号/材料、测试条件、样本量、结果、限制条件和校验值。

### 3.1 证据冲突裁决矩阵（V1.1 定案）
按**文件权威性 × 参数适用性**双维度裁决，不做简单全局优先级：

| 证据类型 | 主要控制内容 |
|---|---|
| 制造商数据手册 | 具体料号的额定值、绝对最大额定值、推荐工作条件 |
| 适用标准 | 测试方法、设计要求、降额或安全要求 |
| 企业规范 | 企业内部设计裕量、应用边界、额外限制 |
| 实测数据 | 特定样品、批次、工况下的实际表现 |

裁决规则：
1. 参数极限值/额定值：料号数据手册（具体料号）优先于通用标准。
2. 降额系数/安全裕度：适用标准或批准企业规范优先于数据手册默认值。
3. 应用边界与验收口径：企业规范优先。
4. 实测数据可支撑工程判断（B 级），不覆盖 A 级判定，但可触发规则修订流程。
5. **硬约束**：企业规范可以比制造商推荐条件更严格，**不得自行放宽制造商绝对最大额定值或适用标准的强制要求**；标准强制要求严于企业规范时，从标准。
6. 无法判断适用性的冲突：系统输出 `CONFLICT_UNRESOLVED`，**阻断自动放行**，转人工评审并记录裁决依据；裁决结果沉淀为该料号/规则域的覆盖标注。

### 3.2 标准文本版权合规（V1.1 定案）
标准库仅存元数据（标准号、版本、条款号、标题）与指向受控副本的引用指针；IEC/ISO/JEDEC/JIS 等受版权保护的标准全文不入库、不展示原文，展示以条款号+适用要点转述并标注出处。标准元数据及受控文件引用机制与部署治理见 01 §9A。

## 4. 生命周期
草拟 → 技术评审 → 单元测试 → 影子运行 → 批准发布 → 监控 → 修订/废止。规则变更需说明原因、影响范围和是否重算历史结果；旧版保留，不物理删除。正式发布双人审批，高风险阈值由可靠性负责人批准。

### 4.1 首批规模目标（V1.1 定案）
- 规则：每关键规则族 ≥10 条、首批合计 ≥60 条（覆盖降额、PCB/PCBA、电源、ESD/EMI 四族）。
- 失效模式库首批 ≤200 条精选（按 01 §5A 高危器件优先原则）。
- 规模超基线时按影子运行结果增补，不一次摊大。数量目标与基准集（03 §4）联动核对。

## 5. 失效模式库结构
按"对象—功能—失效模式—失效机理—诱因—局部影响—上层影响—检测—预防控制—验证"组织。字段包括item_type/name、function、operating_condition、failure_mode、failure_mechanism、root_cause_candidates、local_effect、next_level_effect、end_effect、detection_method、prevention_control、verification_method、evidence_refs、limitations、related_rules/tests、revision、owner。

## 6. 关键规则族
### 元器件降额
电阻：功耗、端电压、脉冲负荷、温度和封装热阻。
电容：电压、纹波、温度、寿命；MLCC偏压降容及压电效应；电解电容寿命模型遵循制造商模型。
半导体：VDS/VCE、ID/IC、SOA、结温、开关损耗、雪崩、栅极应力和热阻链。
连接器：额定电流、接触电阻、温升、插拔次数、振动微动腐蚀。
电池：电压窗口、倍率、温度、循环寿命、保护阈值及运输要求。
晶振：驱动功率、负载电容、频偏和温度稳定性。

### PCB/PCBA
热热点、铜厚/线宽/电流、压降、回流路径、绝缘间距；板弯、螺钉约束、连接器杠杆及振动；焊点几何、热循环疲劳、空洞、润湿、焊盘剥离；离子污染、湿热偏压、CAF、腐蚀、涂覆和清洗残留；钻孔、电镀、层压、回流曲线和贴装偏差。

### 电源
输入浪涌/瞬态、反接、欠压/过压、短路、过温；MOSFET SOA、启动浪涌、过冲与栅极振铃；电感饱和和损耗；电容纹波与寿命；热路径、散热器接触和界面材料老化。

### ESD/EMI
检查ESD路径、回流路径、保护器件布局、寄生电感及接口暴露等级。系统抗扰度需按产品类别和适用标准验证，不能用单一器件耐压替代整机验证。

## 7. DFMEA组织
功能 → 功能失效 → 失效模式 → 失效原因/机理 → 局部影响 → 上层/最终影响 → 现行控制 → 措施。S/O/D或AP采用企业批准评分表，不跨企业混用；AI只建议并解释，工程师确认后入库。默认评分表见附件 `dfmea_scoring_template.md`。

### 7.1 默认评分表模板（V1.1 定案，待企业批准后替换）
详见附件 `dfmea_scoring_template.md`。要点：S/O/D 三档近似（H/M/L），AP 判定网格采用 AIAG-VDA AP 风格；网格仅作建议起点，评分与 AP 定级由工程师按企业批准表确认，AI 输出一律标注「建议值」。

## 8. RAG与生成约束
优先检索同产品、器件、工况和版本；引用必须有来源定位及适用性说明；冲突资料按 §3.1 裁决或并列展示；输出区分证据事实、规则结论、工程推断和待验证假设。禁止编造标准编号、条款、数据手册参数和试验结果；资料不足时明确说明。

## 9. 知识质量与维护
规则单测发布通过率100%；正式规则证据完整率目标100%；监控过期引用、误报/漏报、引用有效率和版本追溯率。领域Owner负责技术内容，知识管理员负责格式/去重，可靠性负责人批准发布。高风险规则至少季度复核；标准或数据手册更新触发影响分析及回归。
新增（V1.1）：规则覆盖率四项指标（见 01 §4A）纳入本节监控范围。
