# AI电子硬件可靠性分析系统｜三件套交付包
版本 V1.1｜2026-11-22（V1.0｜2026-11-21）

## 文件清单
1. `01_系统工程规格书.md`：架构、功能需求、数据模型、API、安全、部署与实施计划。
2. `02_可靠性规则与知识库规范.md`：规则Schema、证据等级、失效模式库、DFMEA及知识维护。
3. `03_验证与验收规范.md`：基准集、测试矩阵、AI评估指标、发布门禁和试点验收。

## 使用建议
- 01用于立项、架构评审及研发任务拆解。
- 02用于规则引擎和可靠性知识库建设。
- 03用于测试团队、领域专家和业务Owner验收。
文中阈值、样本量和KPI均为建议基线，需结合产品、适用标准、企业规范及风险等级批准，不自动构成强制标准。
